# FinSimLab 学習パス

このドキュメントは、FinSimLab のNotebookを使って金融工学とシミュレーションの基礎を順番に学ぶための案内です。

FinSimLabは教育目的のライブラリです。ここで扱うモデル、数値例、シミュレーション結果は、投資判断や金融商品の推奨を目的としたものではありません。

## 前提知識

最初は次の内容が分かっていれば十分です。

- Pythonの基本的な文法
- `list`、関数呼び出し、キーワード引数
- NumPy配列の基本
- 平均、分散、標準偏差の直感
- グラフを見て傾向を読み取ること

数式は最小限にしています。厳密な証明よりも、「パラメータを変えると結果がどう変わるか」を観察することを優先してください。

## 学習順

### 1. `01_random_walk_and_gbm.ipynb`

テーマ: ランダムウォーク、幾何ブラウン運動、平均回帰

最初に学ぶ理由:
価格やリターンをシミュレーションする感覚をつかむためです。後続のオプション価格、VaR、ポートフォリオ分析でも、ランダムな価格変化の考え方が出てきます。

試すこと:

- `mu` を変えて、平均的な方向がどう変わるか見る
- `sigma` を変えて、価格パスの広がりを比較する
- `n_paths` を増やして、多数の経路を見る意味を確認する
- 平均回帰の `speed` を変えて、長期平均へ戻る速さを観察する

### 2. `02_monte_carlo_option_pricing.ipynb`

テーマ: payoff、Black-Scholes、Monte Carloによるオプション価格

次に学ぶ理由:
ランダムな将来価格を使って、金融商品の価値を推定する流れを学べるからです。数式で直接価格を出す方法と、シミュレーションで近似する方法を比較できます。

試すこと:

- `strike` を変えて、コールとプットの価値の変化を見る
- `volatility` を変えて、オプション価格への影響を確認する
- `n_paths` を増やして、Monte Carlo推定値の安定性を見る
- コールとプットを切り替えて、payoffの違いを確認する

### 3. `03_portfolio_risk.ipynb`

テーマ: ポートフォリオの期待リターン、分散、ボラティリティ、近似的な効率的フロンティア

次に学ぶ理由:
金融工学では、個別資産だけではなく、複数資産を組み合わせたときのリスクを見ることが重要だからです。相関や共分散がリスクにどう影響するかを視覚的に確認できます。

試すこと:

- ウェイトを変えて、期待リターンとボラティリティの変化を見る
- 共分散行列の非対角成分を変えて、分散効果を確認する
- `risk_free_rate` を変えて、Sharpe ratioの解釈を試す
- リバランス計算で、現在配分と目標配分の差を確認する

### 4. `04_var_and_cvar.ipynb`

テーマ: 損失分布、VaR、CVaR

次に学ぶ理由:
ポートフォリオや価格変化を扱うだけでは、悪いケースの大きさが見えにくいからです。VaRとCVaRを使うと、損失分布の右側の裾を要約できます。

試すこと:

- `confidence_level` を変えて、VaR/CVaRの変化を見る
- `portfolio_value` を変えて、損失額のスケールを確認する
- シミュレーションの `sigma` を変えて、tail riskの変化を見る
- VaRとCVaRの違いを、自分の言葉で説明してみる

### 5. `05_bonds_and_duration.ipynb`

テーマ: 現在価値、固定利付債、デュレーション、コンベクシティ

最後に学ぶ理由:
ここでは株価やポートフォリオとは違い、将来キャッシュフローを割り引く考え方を学びます。債券価格と利回りの関係は、金融工学の基礎として重要です。

試すこと:

- `yield_to_maturity` を変えて、債券価格がどう変わるか見る
- `coupon_rate` と利回りが同じとき、価格が額面に近いことを確認する
- 満期を長くして、durationの変化を見る
- 利回りと価格の関係が直線ではないことをグラフで確認する

## Phase 6補助機能との関係

Phase 6では、ライブラリ本体の機能追加よりも、学習者が迷わず進めるための教材整備を優先します。

今後追加するとよい補助機能は次の通りです。

- Notebookごとの確認問題を増やす
- 重要な用語をまとめた `docs/GLOSSARY.md` を作る
- 数式の導出を少し詳しく説明する補足資料を作る
- `ipywidgets` を使ったパラメータ操作セルを増やす
- 学習者が結果を記録できる空欄つき演習Notebookを用意する
- StreamlitデモとNotebookを対応させ、ブラウザでも同じ概念を触れるようにする

この段階では、すべてを詳しく説明しすぎるよりも、短い説明、実行できるコード、パラメータ変更の演習を組み合わせる方が学びやすくなります。

## 推奨する進め方

1. Notebookを上から順に実行する。
2. 各Notebookの演習問題で、1つずつパラメータを変える。
3. グラフや数値の変化を短くメモする。
4. 分からない用語をREADMEや今後追加予定の用語集で確認する。
5. 同じ関数を自分の小さなサンプルコードで呼び出してみる。

FinSimLabの学習では、正解を暗記するよりも、モデルの仮定、パラメータ、結果の関係を自分で動かして確かめることを重視します。
