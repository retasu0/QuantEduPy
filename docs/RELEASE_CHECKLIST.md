# FinSimLab OSS公開前チェックリスト

このチェックリストは、FinSimLabをOSSとして公開する前に確認すべき事項をまとめたものです。

## 必須 (Mandatory)

### ライセンスと法務
- [x] `LICENSE` ファイル（MITライセンス）が存在すること。
- [x] README.md に「投資助言、売買推奨ではない」ことを明記すること。
- [x] 主要なNotebookに投資助言ではない旨の免責事項が記載されていること。

### インストールと基本構成
- [x] `pip install -e .` で正常にインストールできること。（Julesの環境で確認済み）
- [x] `pyproject.toml` のメタデータ（名前、バージョン、説明、依存関係）が正しく設定されていること。
- [x] README.md に導入手順と最小限の実行例があること。

### テストと品質
- [x] `python -m pytest` ですべてのテストがパスすること。（Julesの環境で確認済み）
- [x] 主要機能（シミュレーション、オプション、リスク、債券）に対するテストコードが存在すること。

### CI/CD
- [x] GitHub Actions (.github/workflows/tests.yml) で Python 3.10, 3.11, 3.12 のテストが定義されていること。

## 推奨 (Recommended)

### 運営用ドキュメント
- [ ] `CONTRIBUTING.md` （貢献ガイドライン）が存在すること。
- [ ] `SECURITY.md` （セキュリティポリシー）が存在すること。
- [ ] `CODE_OF_CONDUCT.md` （行動規範）が存在すること。

### NotebookとExamples
- [ ] `notebooks/` の各ファイルが最新のAPIでエラーなく動作すること。（要確認）
- [ ] `examples/` の各スクリプトが正常に実行できること。（要確認）

### セキュリティ
- [ ] ソースコードやNotebook内に API キーなどの機密情報が混入していないこと。（要確認）

## 将来対応 (Future)

### CI/CDの強化
- [ ] NotebookのJSON形式検証を自動化すること。
- [ ] examplesの実行検証を自動化すること。

### コンテンツ拡充

- [ ] APIリファレンスの自動生成導線の追加。
- [ ] サンプルギャラリーの作成。
