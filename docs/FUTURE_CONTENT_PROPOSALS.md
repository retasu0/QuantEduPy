# 今後のコンテンツ・機能拡充に関する提案

FinSimLab を金融工学の初学者にとってより価値の高い学習プラットフォームにするため、以下の5つの柱に基づく拡充案を提案します。

---

## 1. シミュレーションモデルの高度化（現実の市場特性を学ぶ）

現在の幾何ブラウン運動（GBM）や平均回帰過程に加え、実市場で見られる複雑な現象を学べるモデルを追加します。

- **ジャンプ拡散モデル (Jump Diffusion)**:
  - 内容: 通常の変動に、突然の暴落や急騰（ジャンプ）を組み合わせたモデル。
  - 教育的意義: 「通常時」と「異常時」を一つのモデルで表現する難しさと重要性を学ぶ。
- **ヘストンモデル (Heston Model)**:
  - 内容: ボラティリティ自体もランダムに変動する確率的ボラティリティモデル。
  - 教育的意義: 「価格が下がるとボラティリティが上がる（レバレッジ効果）」という市場の非対称性を視覚化する。
- **マートン・モデル (Merton Model)**:
  - 内容: 資産価値のシミュレーションに基づき、倒産確率（信用リスク）を算出する。
  - 教育的意義: 株式やオプションの知識が、企業の信用評価にどう繋がるかを学ぶ。

## 2. 歴史的イベントに基づくケーススタディ

理論上の数値だけでなく、実際の市場が直面した危機を再現することで、リスク管理の重要性を体感します。

- **危機シナリオの再現**:
  - リーマンショック、コロナショック、ブラックマンデー等のボラティリティや相関をパラメータとして提供。
  - 「当時のVaR（想定最大損失）はいくらだったか」「実際にはどれほどそれを上回ったか」を検証する。
- **ファットテール (Fat Tails) の理解**:
  - 内容: 現実のリターン分布が正規分布よりも「裾が厚い」ことを、実際のヒストリカルデータと比較して学ぶ。
  - 教育的意義: 理論モデルの限界を知ることで、より保守的なリスク管理の必要性を理解する。

## 3. インタラクティブな学習ツールの導入

コードの書き換えなしで直感的に概念を触れる環境を整備します。

- **Streamlit デモアプリ**:
  - ブラウザ上のスライダーでパラメータ（$\mu, \sigma$ 等）を動かすと、価格パスや効率的フロンティアがリアルタイムに変化する。
- **用語集 (GLOSSARY.md)**:
  - デルタ、ガンマ、コンベクシティ、シャープレシオ等の難解な用語を、ライブラリ内の関数と紐づけて解説。

## 4. ユーザー参加型の演習とゲーミフィケーション

「自分で考えて動かす」ための動機付けを強化します。

- **ポートフォリオ構築ミッション**:
  - 「期待リターン8%以上を維持しつつ、最大損失（VaR）を最小にする資産配分を見つけよ」といった課題形式のNotebook。
- **自動採点クイズ**:
  - 各Notebookの最後に、学んだ概念（「金利が上がると債券価格はどうなるか？」等）をPythonのコードで回答するチェックテスト。

## 5. AIチューター機能の拡張（Phase 6の発展）

現在実装されている説明生成機能を、より対話的で分析的なものに進化させます。

- **対話型シミュレーション解説**:
  - 生成されたグラフに対し、AIが「この結果から読み取れる最大のリスクは何か」「パラメータをどう変えればより安定するか」を統計的に解説。
- **コード生成補助**:
  - 自然言語で「ボラティリティを半分にして再試行して」と指示すると、対応するPythonコードを提案・実行する。
